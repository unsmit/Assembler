AARCH64 / A64 INSTRUCTION FORMS

Plain-ASCII reference for assembler development.

IMPORTANT

A64 is a very large and extensible ISA. The same mnemonic can have
several instruction forms/encodings. This file lists the
base/general-purpose A64 mnemonics and the major FP/SIMD families you
are likely to encounter. Newer architecture extensions (SVE, SVE2, SME,
crypto, MTE, PAUTH, atomics, etc.) add many more forms.

Operand notation: Xd, Xn, Xm, Xa, Xt = 64-bit general-purpose registers
Wd, Wn, Wm, Wa, Wt = 32-bit general-purpose registers Vd, Vn, Vm =
SIMD/vector registers Sd, Sn, Sm = 32-bit FP registers Dd, Dn, Dm =
64-bit FP registers #imm = immediate label = symbol/label cond =
condition code [Xn, …] = memory address based on Xn

============================================================ IMPORTANT
ENCODING CLASSES FOR YOUR ASSEMBLER
============================================================

A64 instructions are ALWAYS 32 bits, but A64 does not use one universal
R-type / I-type / D-type scheme.

1. ADD/SUB SHIFTED REGISTER (“R-TYPE-LIKE”)

Bits: 31 30 29 28-24 23-22 21 20-16 15-10 9-5 4-0 sf op S 01011 shift 0
Rm imm6 Rn Rd

Widths: sf=1, op=1, S=1, fixed=5, shift=2, fixed=1, Rm=5, imm6=6, Rn=5,
Rd=5

2. ADD/SUB IMMEDIATE (“I-TYPE-LIKE”)

Bits: 31 30 29 28-24 23 22 21-10 9-5 4-0 sf op S 10001 0 sh imm12 Rn Rd

Widths: sf=1, op=1, S=1, fixed=5, fixed=1, sh=1, imm12=12, Rn=5, Rd=5

3. LOAD/STORE UNSIGNED IMMEDIATE (“D-TYPE-LIKE”)

Bits: 31-30 29-27 26 25-24 23-22 21-10 9-5 4-0 size 111 V 01 opc imm12
Rn Rt

Widths: size=2, fixed=3, V=1, fixed=2, opc=2, imm12=12, Rn=5, Rt=5

NOTE: This is only ONE load/store layout. Pre-indexed, post-indexed,
unscaled, register-offset, literal, pair, exclusive and atomic forms use
other layouts.

4. UNCONDITIONAL BRANCH IMMEDIATE

B / BL: 31-26 25-0 opcode imm26

Widths: opcode=6, imm26=26

5. CONDITIONAL BRANCH

B.cond: 31-24 23-5 4 3-0 fixed/op imm19 0 cond

Widths: fixed/op=8, imm19=19, fixed=1, cond=4

6. COMPARE AND BRANCH

CBZ / CBNZ: 31 30-25 24 23-5 4-0 sf fixed op imm19 Rt

Widths: sf=1, fixed=6, op=1, imm19=19, Rt=5

7. TEST AND BRANCH

TBZ / TBNZ: 31 30-25 24 23-19 18-5 4-0 b5 fixed op b40 imm14 Rt

8. MOVE WIDE IMMEDIATE

MOVN / MOVZ / MOVK: 31 30-29 28-23 22-21 20-5 4-0 sf opc 100101 hw imm16
Rd

9. PC-RELATIVE ADDRESS

ADR / ADRP: 31 30-29 28-24 23-5 4-0 op immlo 10000 immhi Rd

FINAL NOTE

For an assembler, do not model an A64 mnemonic as: mnemonic -> one
opcode

Model it closer to: mnemonic -> list of legal encoding forms

Example: ADD -> shifted-register form -> extended-register form ->
immediate form

Your parser identifies the mnemonic and operands. Operand validation
selects the legal form. The encoder then writes that form’s 32-bit
fields.

For a literally exhaustive list covering every optional A64 architecture
extension and every encoding variant, use Arm’s current Architecture
Reference Manual / Machine Readable Specification (Instructions.json).
